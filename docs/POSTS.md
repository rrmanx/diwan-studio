## 3. English alternatives

**Professional**

From the first API call to a product.

Diwan Studio: an Arabic studio that searches classical poetry through the AlDiwan API, reads the poem line by line, then composes it and exports artwork.

Try it: diwan-studio.web.app
Open source: github.com/rrmanx/diwan-studio

Built on 14 AlDiwan API endpoints: search, poets, poems, quotes, eras, meters, rhymes.
