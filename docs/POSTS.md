## 4. English alternatives

**Professional**

From the first API call to a product.

Diwan Studio, an Arabic studio for classical poetry: search, read, compose, export.

What you can do:
• Search by poet, or by a line you remember
• Filter by era, meter and rhyme
• Read the full poem with its hemistichs and diacritics
• Pick the verses, then one of three templates
• Set the face, leading, palette and frame
• Export a PNG at 1080×1080, 1080×1350 or 1920 tall
• Use it without an API key: the preview corpus is complete
• Inspect each request: path, status, latency, quota

diwan.rrmanx.com
Open source: github.com/rrmanx/diwan-studio

Built on 14 AlDiwan API endpoints.
